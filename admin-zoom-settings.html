Booking Zoom Settings

Melbourne and Sydney each have their own independent Zoom account, so each gets its own Server-to-Server OAuth app below. Changes apply immediately — no redeploy needed.

How to get these values

1. Create an OAuth app in each Zoom account

  1. Go to the Zoom App Marketplace developer console, signed in as that office's Zoom account.
  2. Click Build App, choose Server-to-Server OAuth, and name it (e.g. "Cameron & Co Booking — Melbourne").
  3. On the app's App Credentials page, copy the Account ID, Client ID, and Client Secret into that office's fields below.

2. Add scopes

Under Scopes, add exactly these three (all :admin, not :master — those are for Zoom partner accounts):

  1. Create a meeting for a user — meeting:write:meeting:admin
  2. Update a meeting — meeting:update:meeting:admin
  3. Delete a meeting — meeting:delete:meeting:admin

Then click Activate on the app. Repeat for the other office's Zoom account.

3. Set the meeting host

Enter the Zoom login email of whoever should host that office's virtual appointments. Every booking gets its own unique meeting link.
